## Community Cleanliness & Issue Reporting Portal

**Clean Connect** is a community-driven web app that empowers citizens to report local issues such as garbage, road damage, illegal constructions, and broken public property _ promoting a cleaner and more sustainable environment.


## Features
- Firebase Authentication (Login, Register, Google SignIn, Reset Password)
- Protected Routes (Add Issue, My Issues, My Contributions)
- Fully Responsive UI using Tailwind CSS
- Real-time issue data from MongoDB
- Dynamic Routing and Toast Notifications
- PDF report generation for user contributions
- Community Stats & Volunteer CTA section on Home Page


## Tech Stack
**Frontend:** React.js, Tailwind CSS, Framer Motion swiper.js 
**Backend:** Node.js, Express.js, cors
**Database:** MongoDB  
**Auth:** Firebase Authentication  
**PDF:** jsPDF, jspdf-autotable  
**Alerts:** react-toastify, sweetalert2
