# GreenNest Indore Plant  Care & Store

## Live Link :-
https://greennest-indore-plants.netlify.app

## Features :-
- Firebase Authentication(Login, Register, google signIn , reset password)
- protected routes (Plant details & my profile)
- responsive design and tailwind css
- json Data for Indore plants
- Dynamic routing and toast notification
  
## Technologies
React.js, React Router, Firebase, Tailwind CSS, React Toastify, react icons, swiper.js, framer motion.
