## Community Cleanliness & Issue Reporting Portal

**Clean Connect** is a community-driven web app that empowers citizens to report local issues such as garbage, road damage, illegal constructions, and broken public property _ promoting a cleaner and more sustainable environment.

Live Site: [https://clean-connect-project.netlify.app](https://clean-connect-project.netlify.app) 

## Overview
CleanConnect is a full-stack MERN application that lets citizens report local issues (garbage, road damage, etc.) and crowdsource contributions to fix them.

## Users: Report issues, contribute funds, track personal activity
## Admins: Manage all issues & contributions

## Fully responsive | Dark/Light mode | Role-based access | Production-ready

## Key Features

## Public Pages
- Home with latest issues
- All Issues: Search, filter (category/status), sort, pagination
- Issue Details: Progress bar, contribution modal & table

## Authentication
- Email/Password + Google Sign-In
- Demo login buttons (User & Admin)

## User Dashboard
- Overview with real-time charts
- My Issues (CRUD)
- Add new issue
- My Contributions (PDF report download)
- Profile update

## Admin Dashboard (Separate panel)
- Manage All Issues (status update, edit, delete)
- Manage Contributions (total stats, search, delete, CSV export)

## Tech Highlights
- Firebase Auth
- MongoDB backend
- Recharts for dynamic charts
- SweetAlert2 & Toast notifications
- Secure role persistence on reload


## Tech Stack

**Frontend**
- React + Vite
- React Router v6 (nested routes)
- Tailwind CSS + DaisyUI
- Firebase Authentication (Email & Google)
- Recharts for charts
- React Toastify & SweetAlert2
- jsPDF + autoTable for PDF reports

**Backend**
- Node.js + Express
- MongoDB
